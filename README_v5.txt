BluetoothGPSApp_PWA_v5 - исправленная версия
Исправления и улучшения:
- Модальное окно теперь отображается поверх карты (увеличен z-index у модалки и понижен у слоёв Leaflet).
- Синхронизированы id кнопок и обработчиков (closeModal, moreBtn и т.д.).
- Добавлена кнопка Отключиться от BLE и отображение имени устройства.
- Проверка поддержки Web Bluetooth и удобные сообщения об ошибках.
- Улучшенный Service Worker с авто-обновлением и кнопкой 'Обновить приложение'.
- Тестовые координаты остались для разработки.

Инструкция:
1) Разверните содержимое репозитория на HTTPS (GitHub Pages).
2) Откройте сайт в Chrome на Android, установите PWA.
3) Один раз при подключении к интернету приложение закэширует файлы для оффлайн-режима.
4) Для обновления: залейте новые файлы в репозиторий, пользователь увидит кнопку 'Обновить приложение' и сможет применить новую версию.
